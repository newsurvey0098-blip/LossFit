## In progress
- The first dashboard and catalogue views and initial persisted API are foundations only.
- Dashboard numbers and hydration, catalogue search, manual foods, food detail portion selection, meal logging, profile goals, and data exports now use the authenticated API.
- Short-lived access JWTs are kept in frontend memory; rotating 30-day refresh tokens are hashed in PostgreSQL and sent in HttpOnly SameSite=Lax cookies, with the Secure flag enabled in production. CSRF and configured-origin checks cover refresh and logout. Refresh rotation, replay rejection, logout revocation, and authorization checks are included in the automated suite. Verified imported public catalogue data, OAuth linking, browser E2E, backup restore drill, and broad security/accessibility review remain outstanding. Persistent database-backed limits cover registration, login, reset requests/attempts, scanner uploads/confirmation, assistant calls, and refresh; only scanner limits currently have an explicit regression test. Scanner upload/review/confirmation flows are implemented and provider behavior was tested with a deterministic mock; live vision credentials are unavailable and the live provider is unverified. Analytics/log/scanner routes have not received browser/manual visual verification. Password recovery endpoints and screens are implemented; SMTP delivery is unverified. Account deletion removes personal records and scanner files and stores an HMAC email marker; automated restore-time replay and retryable file cleanup are not yet implemented.
- Source-linked learning lessons, explanation levels, quizzes, private progress persistence, reviewed/versioned RAG sources, chunking, lexical retrieval, source citations, and abstention when there are no relevant chunks are implemented and API-tested. Embeddings are supported when configured, but no embedding provider was available during verification; provider behavior is unverified. RAG currently uses a portable JSON vector/lexical adapter rather than pgvector. The public food catalogue is not yet populated with verified imported records.
